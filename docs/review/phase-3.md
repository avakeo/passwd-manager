## 残した課題

- 拡張機能からのコピーでは、クリップボードの履歴のアプリが無視する印（macOS の org.nspasteboard.ConcealedType）を付けられない。履歴のアプリの設定で除外してもらうしかない。
- 見えている欄かの判定は見た目によるので、ほかの要素の下に重ねて隠した欄や、文字の色を背景と同じにした欄は防げない。自動入力をポップアップからだけにし、オリジンの完全一致と組み合わせて補う。
