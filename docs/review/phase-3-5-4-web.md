## 残した課題

- DeepSeek #4 の確認は、この端末が同期で知っているアイテムとだけ比べる。同期のときにサーバーがアイテムを削除したように見せた場合は、端末の一覧からも消えるので気づけない（仕様書の「ロールバックと隠蔽」の範囲）。
- 照合の画面の「自分の鍵」は、マスターパスワードで解除していないと出なくなった。クイックロック解除やロック解除を保つで戻った状態では、照合の前にマスターパスワードを求める。
- 画面の文言（「マスターパスワードでロックを解除すると出ます」、ITEMS_MISSING の文）は、手でまだ確かめていない。
