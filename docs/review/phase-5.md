## 判断の記録（2026-10-29）

- ロック解除を保つ：Vault 鍵を暗号化せずに storage.session に置く。包む鍵を同じ場所に置くことになり、守りが増えないため。ディスクに置く案（ブラウザを閉じても残す）は採らなかった。
- この端末を覚える：手元で間違いを数えるだけでは、ディスクを読める人がトークンを直接使えるので、サーバーで数える。HMAC の鍵は新しいシークレットを足さず、TOTP 暗号化用のサーバー鍵から HKDF で別の用途として作った。

## 残した課題

- この端末を覚えた端末を盗まれると、7日の間、パスコードを3回まで試される。当てられると API を使われる（中身を読むにはマスターパスワードが要る）。
- ロック解除を保つ設定がオンの間は、ブラウザを開いたまま離れると、その端末を触れる人がアイテムをすべて見られる。
