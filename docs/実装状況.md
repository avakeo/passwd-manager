## 4. HPKE（C-15）とテストベクタ

- CFRG の test-vectors.json に、本番の組（Base モード、KEM 0x0010・KDF 0x0001・AEAD 0x0002）があった。enc、shared_secret、key_schedule_context、secret、key、base_nonce と、257件の暗号文が、送り手と受け手の両方で一致した。付録 A.3 の組（AEAD 0x0001）も一致した。
- 仕様書の条件（この組で確かめた場合だけ「RFC 9180 準拠」と書く）を満たすので、README には「RFC 9180 の Base モードに準拠」と書いた。仕様書の本文は書き換えていない。
- **HPKE のベクタはコミットしていない**。CFRG のリポジトリにはライセンスファイルがなく、CONTRIBUTING.md の「IETF TLP、コードの部分は Simplified BSD」に JSON が当たるかを確認できなかったため（決定事項：ライセンスが確認できないものは置かない）。scripts/fetch-vectors.ts で、コミットを固定した URL から取り、SHA-256 を照合して tests/vectors/.cache（Git の管理外）に書き出す。docs/判断待ち.md の2。
- Wycheproof（Apache-2.0）は、ライセンスの全文と一緒に tests/vectors/wycheproof に置いた。
