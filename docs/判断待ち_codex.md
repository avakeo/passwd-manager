# 判断待ち（Codex：独立したクライアント部品）

このファイルは仕様書にない細部の案と、フェーズ3で実機確認する項目の記録。仕様書自体は変更していない。

## 実装時に置いた案（レビュー待ち）

| # | 論点 | 今回の案 | 対象 |
|---|---|---|---|
| 1 | パスワードの文字集合と長さ | 英小文字・英大文字・数字・記号 `!@#$%^&*()-_=+[]{}:,.?` を既定で使う。長さは既定20、上限65,532。使用する集合が2文字未満なら拒否。選んだ文字種の各種が必ず1文字ずつ入る保証は設けず、全候補から一様に選ぶ。強度の表示値は `長さ × log2(候補数)`。テスト用の任意の文字集合も指定可能。 | C-11 |
| 2 | 紛らわしい文字 | `0 O 1 l I` を除外する。 | C-11 |
| 3 | 自動入力の判定入力 | 呼び出し側がポップアップ操作・ロック状態・トップフレーム・タブID・文書ID・入力直前のURLを取得して渡す。判定関数はHTTPSのオリジンを正規化して比較する。これらの値の取得元が信頼できるかは拡張機能側で確認する。 | E-01〜05、07、11、13 |
| 4 | アイテム JSON の形 | ログインは `type,title,username,password,urls,notes,customFields`、メモは `type,title,body`。カスタム項目は `type`（text/hidden/date）、`label`、`value`。日付は厳密な `YYYY-MM-DD`。未知の項目は拒否。URLはHTTPSオリジンだけを保存。64KiB のパディング枠に4バイトの長さが入るので JSON は65,532バイト以内。 | I-01、I-02 |
| 5 | CSV の列対応 | Chrome は `name,url,username,password,note`、Proton Pass は `name,url,username,password,note`、1Password は `Title,Website,Username,Password,Notes` を主に対応。見出しは大小文字を区別せず、順番も自由。未知の列に値があればプレビューの警告に出す。形式が変わった実ファイルはフェーズ3でサンプル照合する。 | I-02 |
| 6 | CSV の重複候補 | タイトル（小文字化）・ユーザー名（小文字化）・URLの集合が同じなら重複候補にする。パスワードは比較しない。既存アイテムも引数で渡せる。重複を捨てる処理は設けず、プレビューに印だけ付ける。 | I-02 |
| 7 | CSV の壊れた行 | 不正な引用符・列数違い・不正なURL・サイズ超過は行番号付きで報告して後続を読み続ける。閉じ忘れの引用符が最終行まで続いたら、最初の改行以後を再解析して回復を試みる。複数行の壊れ方によって回復した行も要確認。 | I-01、I-02 |
| 8 | 未対応のCSVデータ | TOTPやタグ等は取り込まない。非空の未対応列がある行は警告する。確認画面で利用者が気づけるようにする。 | I-02 |
| 9 | クリップボードの判定 | コピー時刻から60,000ms以上経ち、現在の内容がコピーした文字列と同じ非空文字列なら消去可と返す。タイマー・OSの読み書きはフェーズ3。 | E-10、E-12 |

CSV列の確認に使った公開資料：[1Password CSV export](https://support.1password.com/export/)、[Proton Pass CSV export](https://proton.me/support/pass-export)、[Chrome CSV](https://support.google.com/chrome/answer/13068232)。各サービスの実ファイルの全列は仕様として確定していない。

## フェーズ3で実機・統合確認する E 系

| ID | 関数で確認した範囲 | フェーズ3で残る確認 |
|---|---|---|
| E-01 | HTTPS・登録オリジン一致を許可 | 実際のフォームへ入力できるか |
| E-02 | トップフレーム以外を拒否 | iframeへ注入されないか |
| E-03 | HTTPを拒否 | HTTPタブで注入されないか |
| E-04 | ドメイン・サブドメイン・ポートの差を拒否 | アドレスバーとの照合経路 |
| E-05 | www差を拒否 | wwwの登録・表示・入力 |
| E-06 | — | 見えない入力欄への入力を拒否する DOM 判定 |
| E-07 | 操作なしフラグを拒否 | ページ読み込みやWebページから勝手に呼べないか |
| E-08 | — | 偽メッセージを拒否する拡張機能の入口 |
| E-09 | — | 注入スクリプトへ対象1件のみ渡すか |
| E-10 | 60秒・内容一致の判定 | 実タイマーとクリップボードの読み直し、他のコピーを消さないか |
| E-11 | ロック状態フラグを拒否 | ロック解除 UI への案内 |
| E-12 | 非表示項目のデータ型と同じ消去条件 | 非表示項目の実コピー・消去 |
| E-13 | 別オリジン・別文書・別タブを拒否 | 注入直前の実URLと文書IDの取得、遷移との競合 |
| E-14〜18 | — | Service Worker停止、パスコード5回失敗、storage.session権限、管理操作、再起動 |

プレビュー・確認画面では CSV 由来の値をテキストとして扱い、HTMLとして解釈しないこと。元CSVを削除する案内と、一括暗号化送信はフェーズ3で実装する。
